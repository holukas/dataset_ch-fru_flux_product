# CH-FRU Flux Dataset Preparation

Welcome to the documentation for the preparation of the CH-FRU eddy covariance flux dataset.

This book describes all processing steps applied to transform raw measurements from the
CH-FRU grassland flux tower into a quality-controlled, gap-filled dataset ready for scientific use.

## Site

CH-FRU is a permanent grassland site in Switzerland, part of the Swiss FluxNet network.

## Processing Steps

The dataset preparation follows these main steps:

1. **Data description** — overview of raw input data and measurement setup
2. **Meteoscreening** — quality control of meteorological variables
3. **Outlier detection** — identification and removal of flux outliers
4. **Gap-filling** — filling missing values using standard methods
5. **Final dataset** — description of the final published dataset
